프로젝션 매퍼

브라우저만으로 작은 입체물(레고 모형 등)의 면에 영상을 맞춰 투사합니다.

편집기 (PC)면을 만들고, 모서리를 끌어 맞추고, 소스를 지정합니다. 출력 화면 (프로젝터)프로젝터에 띄우는 화면입니다. 두 번 눌러 전체화면. 편집 표시가 전혀 없습니다. 폰 리모컨폰에서 점을 골라 끌거나 방향 버튼으로 1px·10px 씩 옮깁니다.

처음 쓰는 순서

  1. 프로젝터를 PC 에 연결하고 프로젝터의 키스톤(사다리꼴) 보정은 끕니다. 보정은 이 앱에서만 합니다.
  2. 편집기에서 출력 창 열기 → 그 창을 프로젝터 화면으로 옮기고 두 번 눌러 전체화면.
  3. 편집기 또는 폰 리모컨에서 면의 모서리를 모형의 모서리에 맞춥니다. 처음엔 격자 패턴으로 맞추면 쉽습니다.
  4. 맞춘 뒤 면마다 영상·효과를 고르고, 저장으로 JSON 파일을 받아 둡니다.

폰 리모컨은 npm run dev(또는 npm start)로 서버를 켰을 때 같은 와이파이에서 씁니다. 서버 화면에 뜨는 QR 을 찍으세요.
